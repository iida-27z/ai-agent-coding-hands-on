# Git規約

本プロジェクトにおける Git 操作およびコミットメッセージの標準ルールです。
必ず作業ブランチを作成し、コミットメッセージのフォーマットに従って記述してください。

## コミットメッセージのフォーマット

コミットメッセージは以下の形式に従って記述してください。
short summaryとoptional bodyは必ず**日本語で記述**してください。

```
<type>: <short summary>

[optional body]
```

### Type一覧
- `feat`: 新機能の追加
- `fix`: バグ修正
- `test`: テストの追加・修正
- `perf`: パフォーマンス改善
- `refactor`: リファクタリング（機能追加やバグ修正を含まないコード変更）
- `style`: コードのスタイル変更（機能追加やバグ修正を含まないコード変更）
- `docs`: ドキュメントの更新
- `ci`: CI/CD関連の変更
- `chore`: ビルドプロセスや補助ツールの変更

## Git操作の禁止事項
- ビルドエラーやテスト失敗状態のコードをコミットしないこと。
