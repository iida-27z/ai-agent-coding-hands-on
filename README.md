# カンバンボード コンソールアプリケーション (Kanban Board Console App)

Java 25 で構築された、CUI（コンソール）対話型のカンバンボードタスク管理アプリケーションです。  
3つのステータス（`TODO` / `DOING` / `DONE`）を縦並びで可視化し、タスクの登録・進捗変更・削除を直感的に操作できます。

---

## 1. 主な機能と特徴

- **縦並びカンバンボード表示**:
  - `TODO`（未着手）→ `DOING`（進行中）→ `DONE`（完了）の順にセクションを縦方向に配置し、ターミナル幅に依存せずタスク全体を一目で把握可能。
  - 各ステータスのタスク件数表示およびタスクが存在しない場合の `(タスクなし)` 案内。
- **対話型コンソールメニュー**:
  - メニュー番号選択による直感的な操作（1: ボード表示, 2: タスク追加, 3: ステータス変更, 4: タスク削除, 0: 終了）。
  - 不正な入力（存在しないID、空のタイトル、無効な選択肢）に対する安全なエラーハンドリング（アプリが異常終了せずメニュー待機に戻る）。
- **Java 25 言語機能の活用**:
  - 不変レコード (`record`)、拡張 switch 文・パターンマッチングを活用した堅牢な設計。
- **クリーンなレイヤードアーキテクチャ**:
  - Domain, Repository, Service, UI (Presentation) のレイヤー分離と、入出力インターフェース抽象化による高いテスタビリティ。

---

## 2. システム要件 (Prerequisites)

- **Java**: JDK 25 以上
- **Apache Maven**: 3.9 以上

## 3. アーキテクチャとディレクトリ構成

### 3.1 レイヤー構成

```text
com.example.kanban
├── Main.java                          // アプリケーションエントリーポイント

│   ├── model
│   │   ├── TaskId.java               // タスクID値オブジェクト (record)

│   │   └── Task.java                 // タスクエンティティ (record)

│       ├── KanbanException.java      // 基底例外
│       ├── TaskNotFoundException.java// タスク不在例外
│       └── ValidationException.java  // 入力値バリデーション例外
├── repository                         // リポジトリ層（永続化抽象・実装）
│   ├── TaskRepository.java           // リポジトリインターフェース
│   └── InMemoryTaskRepository.java   // スレッドセーフなインメモリ実装
├── service                            // サービス層（ユースケース）
│   ├── KanbanService.java            // カンバンサービスインターフェース
│   ├── KanbanServiceImpl.java        // サービス実装クラス
│   └── dto
│       ├── CreateTaskCommand.java    // タスク登録コマンド (record)
│       └── KanbanBoardView.java      // ボード表示用集約DTO (record)
└── ui                                 // プレゼンテーション層（コンソールUI）
    ├── io
    │   ├── ConsoleIo.java            // コンソール入出力インターフェース
    │   └── StandardConsoleIo.java    // 標準入出力実装
    ├── render
    │   └── KanbanBoardRenderer.java  // 縦並びボード文字列フォーマッタ
    └── KanbanConsoleApp.java         // 対話型コンソールアプリケーション制御
```

## 4. ビルド・テスト・実行手順

### 4.1 プロジェクトのビルド

Maven を使用してプロジェクトをクリーンビルドおよびパッケージングします。

```bash
mvn clean package
```

ビルドが完了すると `target/kanban-board-console-app-1.0.0-SNAPSHOT.jar` が生成されます。

### 4.2 テストの実行

JUnit 5 / AssertJ / Mockito による全テスト（76件）を実行します。

```bash
mvn test
```

### 4.3 アプリケーションの実行

#### 方法 A: Maven Exec プラグインによる実行 (推奨)

```bash
mvn exec:java -Dexec.mainClass="com.example.kanban.Main"
```

#### 方法 B: クラスパスを指定して Java コマンドで実行

```bash
java -cp target/kanban-board-console-app-1.0.0-SNAPSHOT.jar com.example.kanban.Main
```

## 5. 操作ガイドと画面例

### 5.1 メインメニュー

起動すると以下のメニューが表示されます。

```text
==================================================
       カンバンボード アプリケーションへようこそ       
==================================================
--- メニュー ---
1. カンバンボードを表示
2. タスクを追加
3. タスクのステータスを変更
4. タスクを削除
0. 終了
メニュー番号を選択してください: 
```

### 5.2 カンバンボード表示 (メニュー: 1)

`TODO`、`DOING`、`DONE` が縦方向に整列して出力されます。

```text
==================================================
                 KANBAN BOARD                     
==================================================

[ TODO ] (2 tasks)
--------------------------------------------------
  #1: ログイン画面の作成
      説明: Spring Securityを用いた認証画面
  #2: データベース設計
      説明: ER図の作成とマイグレーション

[ DOING ] (1 task)
--------------------------------------------------
  #3: APIエンドポイント実装
      説明: RESTful APIのコントローラー作成

[ DONE ] (1 task)
--------------------------------------------------
  #4: 要件定義
      説明: 仕様書とタスク分解の作成

==================================================
```

### 5.3 タスクの追加 (メニュー: 2)

タイトル（必須）と説明（省略可）を入力して新しいタスクを作成します（初期ステータスは `TODO`）。

```text
[ タスクの追加 ]
タイトル: UIコンポーネントの実装
説明 (省略可): ボタンとダイアログのスタイル適用
タスク #5 を追加しました: UIコンポーネントの実装
```

### 5.4 タスクステータスの変更 (メニュー: 3)

タスクIDと新しいステータス（1-3 または TODO/DOING/DONE）を指定して進捗を更新します。

```text
[ タスクステータスの変更 ]
タスクID: 1
選択可能なステータス:
  1: TODO (未着手)
  2: DOING (進行中)
  3: DONE (完了)
新ステータス (1-3 または TODO/DOING/DONE): 2
タスク #1 のステータスを [進行中] (DOING) に変更しました。
```

### 5.5 タスクの削除 (メニュー: 4)

タスクIDを指定してカンバンから削除します。

```text
[ タスクの削除 ]
削除するタスクID: 4
タスク #4 を削除しました。
```
